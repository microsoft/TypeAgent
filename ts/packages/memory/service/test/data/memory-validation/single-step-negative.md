# Shift acknowledgement policy

The policy records who accepted a completed Aurora-7 validation, but it does
not define calibration or deployment work. Detailed actions remain in the
approved runbook and release checklist.

## How to acknowledge an Aurora-7 validation result

1. Sign the maintenance record with the incident ID, active source revision, and gateway sequence number.

One acknowledgement is intentionally insufficient for procedure candidate
detection. This document is the minimum-step negative control.
