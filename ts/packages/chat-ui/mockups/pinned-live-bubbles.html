Pinned live bubbles

A live-updating bubble (like the background “Indexing…” progress) can scroll out of view while the user reads other messages. These mockups keep that live bubble reachable when it leaves the viewport, with a pin control that hands scrolling back to the user.

Scroll the chat to push a live bubble off-screen.
TypeAgent · Shell

The bubble classes and progress-bar markup mirror packages/chat-ui and the dispatcher’s renderConversationIndexProgress(), so this maps directly onto ChatPanel.setDynamicDisplay. Pinning is driven by an IntersectionObserver watching the live bubble.

  • 📌 Pin toggle — armed by default for live bubbles. Click it (on the bubble, the dock, or the pill) to disable pinning and return that bubble to normal scroll behavior; click again to re-arm.
  • Jump — click a docked card or the expanded pill to scroll the real bubble back into view.
  • The mode is stored in the URL hash — open this file in several tabs (each on a different mode) to compare them side by side.
