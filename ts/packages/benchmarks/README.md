# @typeagent/benchmarks

Action-translation eval for TypeAgent: pinned catalogs, model prices, and scoring harness.

## Default generation models

New translation-benchmark generation and review runs default to
`azure/gpt-6.1-sol`. Default ambiguity probes request `gpt-6.1-sol`,
`gpt-6.1-terra`, and `gpt-6-luna`. Dispatcher collision-corpus generation uses
the corresponding `GPT_6_1_SOL`, `GPT_6_1_TERRA`, and `GPT_6_LUNA` deployment
selectors.

The action-quality picker defaults to `GPT_6_1_SOL`; override it with
`TB_PICKER_MODEL` or `--model`. The package command works without shell-specific
environment-variable expansion.

Explicit evaluation/comparison models remain unchanged, including the GPT-4.1
models in the example run config. Historical artifacts and generated pricing
tables are not relabeled or regenerated by this migration. Current GPT-6 prices
must be supplied from verified rates before relying on monetary cost reports.
Azure pools do not automatically fall back to older model families.

## Conversation-memory benchmarks

The [BEAM runbook](src/memoryBench/README.md) covers the TypeScript
memory harness, offline tests, pinned protocol preparation, live execution and
resume. It calls the durable memory service directly and requires no Python.

## Catalog + action-parameters grader

Pinned `catalog.generated.json` and `action-parameters-grader.generated.json`. Code/script parameters use verify mode `llmAsAJudge` (not exact); synthesizer exclusions are derived from those fields. Regenerate with `pnpm run gen-catalog` (`--force` full rebuild). Tests: `pnpm run test:local`.

## Dataset synthesizer (part 3)

Simple-action dataset generation only (one expected action per positive/seed).

- Core: `src/translationBench/synthesizer/` — benchmark JSONL, source import, LLM labeler, quality verifier
- Default shape: `mode: "simple"` via `actionShape.ts` (multi reserved for a later PR)
- Seed example: `synthesizer/seed/`
- Unit tests: `test/translationBench.{benchmark,datasetGenerator,sourceBuilder}.spec.ts`

```bash
cd ts/packages/benchmarks && pnpm run build && pnpm run jest-esm --testPathPattern="translationBench\.(benchmark|datasetGenerator|sourceBuilder)"
```
