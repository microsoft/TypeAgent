# @typeagent/selfhelp-agent

The TypeAgent **Help** agent. It tells you the TypeAgent command - and the
equivalent natural-language phrasing - for what you want to do, answering
"what's the command for X" / "how do I X in TypeAgent".

It ships enabled by default. Ask in natural language (no `@` prefix), for
example:

- "what's the command to create a new conversation?"
- "how do I clear the chat history?"

or invoke it explicitly:

```
@selfhelp create a new conversation
```

A typical answer shows both ways to do it - the `@`-command and the phrasing you
can just say:

- `@conversation new [<name>]` — Create a new conversation, optionally with a name
  or say: "start a new conversation", "new conversation called design review"

## Relationship to `@help`

This agent does **not** replace the built-in `@help` command. `@help` is the
deterministic command reference (usage, arguments, and flags). The Help agent
maps a natural-language intent to the matching command(s)/action(s) and explains
them.

## How it works

The agent is grounded on the **Action Browser catalog** (`action-browser.json`),
which lists every agent action (with example phrasings) and every `@`-command,
including the explicit command→action links (e.g. `@conversation new` ↔ the
`newConversation` action). The catalog is generated by `@typeagent/action-browser`
as part of the docs build and copied into this package's `dist/` at build time
(see `scripts/copyCatalog.mjs`); nothing is fetched at runtime.

For each question, the handler (`src/selfHelpActionHandler.ts`):

1. selects the relevant slice of the catalog (`src/catalog.ts`), keeping each
   command together with its linked action;
2. asks the model, via **TypeChat**, to pick the matching capability as a typed
   `CommandHelpResponse` (`src/commandHelpResponseSchema.ts`) - using only entries
   from the catalog;
3. renders the result to Markdown (`src/render.ts`), resolving each command's
   usage and its paired phrasings from the catalog so the output stays grounded.

Because the command→action links are read from the catalog, more commands light
up automatically as they are annotated - no changes needed here.

## Build & test

```
pnpm --filter @typeagent/selfhelp-agent build
pnpm --filter @typeagent/selfhelp-agent test
```

Build compiles the handler (`tsc`), the routing action schema
(`asc` -> `dist/selfHelpSchema.pas.json`), and copies the catalog into `dist/`.
