## Overview

The `@typeagent/selfhelp-agent` package provides a Help agent for the TypeAgent ecosystem. Its primary purpose is to assist users by answering questions about how to perform tasks within TypeAgent. It translates natural-language queries, such as "how do I create a new conversation?", into actionable TypeAgent commands and their equivalent natural-language phrasings. This agent is enabled by default and can be invoked either implicitly through natural-language queries or explicitly using the `@selfhelp` prefix.

This agent complements the built-in `@help` command by offering a natural-language interface grounded in the Action Browser catalog, which contains a comprehensive list of all available agent actions, `@`-commands, and their explicit links.

## What it does

The Help agent is designed to map user queries to the corresponding `@`-commands and natural-language phrasings. For example:

- Query: "What's the command to create a new conversation?"
- Response:
  - `@conversation new [<name>]` — Create a new conversation, optionally with a name.
  - Or say: "start a new conversation", "new conversation called design review".

### Key Features

1. **Natural-Language Query Support**: Users can ask questions in plain language, such as "how do I clear the chat history?".
2. **Command and Action Mapping**: The agent identifies the relevant `@`-commands and their linked actions, providing both the command syntax and natural-language alternatives.
3. **Grounded Responses**: All responses are based on the Action Browser catalog, ensuring accuracy and consistency.
4. **Automatic Updates**: As new commands and actions are annotated in the catalog, they become available to the Help agent without requiring changes to its code.

### Actions

The agent implements the `answerTypeAgentQuestion` action, which takes a user's question as input and returns a structured response containing the relevant commands and phrasings. This action is grounded in the Action Browser catalog, ensuring that the responses are accurate and up-to-date.
