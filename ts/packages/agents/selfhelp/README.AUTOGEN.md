## Overview

The `@typeagent/selfhelp-agent` package provides a Help agent for TypeAgent. Its primary role is to answer user questions about how to perform tasks within the TypeAgent ecosystem. It translates natural-language queries like "how do I create a new conversation?" into actionable TypeAgent commands and their equivalent natural-language phrasings. This agent is designed to assist users in navigating and utilizing TypeAgent's capabilities effectively.

The agent is enabled by default and can be invoked either implicitly through natural-language queries or explicitly using the `@selfhelp` prefix.

## What it does

The Help agent is built to answer questions about TypeAgent commands and actions. It works by mapping user queries to the corresponding `@`-commands and natural-language phrasings. For example:

- Query: "What's the command to create a new conversation?"
- Response:
  - `@conversation new [<name>]` — Create a new conversation, optionally with a name.
  - Or say: "start a new conversation", "new conversation called design review".

The agent does not replace the built-in `@help` command, which provides deterministic command references. Instead, it complements it by offering a natural-language interface grounded in the Action Browser catalog. This catalog contains a comprehensive list of all available agent actions, `@`-commands, and their explicit links.

### Key Features

1. **Natural-Language Query Support**: Users can ask questions in plain language, such as "how do I clear the chat history?".
2. **Command and Action Mapping**: The agent identifies the relevant `@`-commands and their linked actions, providing both the command syntax and natural-language alternatives.
3. **Grounded Responses**: All responses are based on the Action Browser catalog, ensuring accuracy and consistency.
4. **Automatic Updates**: As new commands and actions are annotated in the catalog, they become available to the Help agent without requiring changes to its code.

### Actions

The agent implements the `answerTypeAgentQuestion` action, which takes a user's question as input and returns a structured response containing the relevant commands and phrasings.

## How to extend

To extend the functionality of the Help agent, follow these steps:

1. **Update the Action Browser Catalog**: Add new commands, actions, or phrasings to the Action Browser catalog. The catalog is the primary source of truth for the agent's responses. Once updated, rebuild the catalog and copy it into the `dist/` directory.

2. **Modify the Handler Logic**: If additional processing is required, update the handler in [selfHelpActionHandler.ts](./src/selfHelpActionHandler.ts). For example, you might add custom logic for handling specific types of queries.

3. **Adjust the Response Schema**: If the structure of the agent's response needs to change, update the schema in [commandHelpResponseSchema.ts](./src/commandHelpResponseSchema.ts). Ensure that the changes are reflected in both the TypeScript types and the TypeChat schema text.

4. **Test Your Changes**: Add or update tests to cover the new functionality. Run the test suite to ensure that everything works as expected:

   ```bash
   pnpm --filter @typeagent/selfhelp-agent test
   ```
