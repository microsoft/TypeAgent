# Local shopping selector prototype (Experiment 4)

This is a controlled localhost fixture, not retailer automation. It supports
search, a cordless filter, and product details. There are no purchase, cart,
checkout, login, external assets, or CAPTCHA paths.

## Implementation

- `observer.mjs` is a host-owned DOM observer. It enumerates visible eligible elements, creates
  snapshot-scoped IDs, and owns selectors, allowlisted methods, and argument
  strings. Decisions receive only IDs and element evidence.
- Choice plus a predicate fit gate selects an ID or `no_fit`. The prototype
  conservatively requires fit >= 0.8; this threshold is not calibrated.
- Before execution, the host checks document identity, mutation revision, node
  identity, visibility, uniqueness, and the live target fingerprint. Changed
  targets fail with `reobserve`; the caller makes a new observation, with no
  hidden model fallback.
- `browser.mjs` directly imports the existing Playwright 1.57.0 dependency and
  launches installed Chromium, Edge, or Chrome in an isolated temporary persistent
  context, removed on close. The fixture server binds an
  ephemeral port on 127.0.0.1 and serves only the two owned fixtures.
- The bounded executor uses Playwright locators for host-validated `click`,
  `fill`, and `press("Enter")` actions. It contains no generative client. Reports
  identify `automation: "playwright"` and structural `explicitActModelCalls: 0`,
  not a measured SDK counter. No SDK inference metrics are fabricated.

Stagehand and its multi-provider dependency fanout have been removed. Only `host`
is supported. `native` and `rerank` flags remain for explicit `unavailable` results,
including `--dry-run`; they never fall back to host execution. Copilot/TypeAgent
supports chat and responses, but a native observation baseline would require a
custom client implementation. Missing provider secrets are not the blocker.

## Commands

From the repository root in PowerShell:

```powershell
if (Test-Path $PROFILE) { . $PROFILE }
Get-Item ts/.npmrc | Select-Object FullName,Length
node ts/examples/decision/web-shopping/run.mjs --dry-run
node ts/examples/decision/web-shopping/run.mjs
node --test --test-concurrency=1 ts/examples/decision/web-shopping/observer.spec.mjs ts/examples/decision/web-shopping/browser.spec.mjs ts/examples/decision/crossword/crossword.spec.mjs ts/examples/decision/crossword/browser.spec.mjs
$cli = Get-Command copilot -CommandType Application | Select-Object -Last 1 -ExpandProperty Source
node ts/examples/decision/web-shopping/run.mjs --live --limit 2 --cli-path $cli
node ts/examples/decision/web-shopping/run.mjs --variant native --dry-run
node ts/examples/decision/web-shopping/run.mjs --variant rerank --dry-run
Get-ChildItem ts/examples/decision/web-shopping,ts/examples/decision/crossword -Filter *.mjs | ForEach-Object { node --check $_.FullName; if ($LASTEXITCODE) { throw $_.Name } }
node ts/node_modules/prettier/bin/prettier.cjs --write ts/examples/decision/web-shopping ts/examples/decision/crossword ts/examples/decision/README.md
node ts/node_modules/prettier/bin/prettier.cjs --check ts/examples/decision/web-shopping ts/examples/decision/crossword ts/examples/decision/README.md
```

Default execution is explicitly offline with a fixture-only deterministic
selector. `--live` enables Copilot decisions for host, not external
browser navigation. `--limit` is restricted to 1 or 2. `--model` overrides the
decision model ID. Native/rerank are unavailable regardless of flags; no new
provider secrets are required or requested.
Search/fill is covered in the local browser specs; smoke tasks are filter and
detail. Abstention or failure writes evidence and returns a failing exit code.

## Blockers And Limits

- Native/rerank baselines are unimplemented after Stagehand removal, not blocked
  by missing credentials. The former SDK/native adapter tests are no longer
  evidence of a current baseline.
- The pre-removal Stagehand installation encountered a transitive Google
  build-script approval gate. Removing Stagehand removes that dependency fanout;
  this migration performs no installation or approval changes.
- Current screenshots are regenerated directly from the owned Playwright page,
  without a Stagehand CDP connection.
- This enumerator intentionally requires owned `data-fixture-id` and
  `data-shopping-action` annotations; it is not a general site adapter.
- Full repository build/lint/complexity/circular/debt gates are left to the
  parent consolidation. No shared source, peer directory, branch, or commit
  was changed by this lane.
